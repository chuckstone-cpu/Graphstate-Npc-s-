# Outwit

Open in Godot 4.5: Project Manager -> Import -> `project.godot` -> Run (F5).

## Controls (you are the knight)
| Key | Action |
| --- | --- |
| WASD / arrows | move |
| Space | sword swing (hits the 3 tiles in front of you, smashes barrels) |
| Shift or right mouse (hold) | raise shield: absorbs damage, wears out, half speed, no swinging |
| E | lock / unlock the nearest door (locking costs 2 mana) |
| Q | drop a barrel barricade (1 mana) |
| M | full castle map (minimap is always top-right) |
| Tab | show the thief's mind: field of view, path, plan, utilities, search stats |
| R | restart |

Blue potion +3 mana, red potion +35 HP. Only the knight can use potions.

## Win / lose
- You win if you kill the thief (50 HP, two sword hits).
- The thief wins if it kills you or carries the chest out of the entrance (bottom left).
- The thief is faster than you, even while carrying the chest.

## How the thief thinks (scripts/agent/thief.gd)
Every time it reaches a tile it runs: sense -> decide -> plan -> act.
- **Sense:** 7-tile field of view with line of sight. It knows the castle blueprint but not which doors you locked or where you put barricades until it sees them (castle_belief.gd).
- **Decide:** utility scores pick steal / fight / flee from its health, weapon and your position. A standoff makes it back off and try another route.
- **Plan (steal):** compares A* costs of "go straight in" versus "fetch a weapon first". Heavy weapons smash locked doors, and only the hammer breaks the cracked wall. It then follows the chosen plan with D* Lite, which repairs the path when things change.
- **Fight:** minimax with alpha-beta pruning over a small turn-based model of the duel. Your sword covers the arc in front of you, so it tries to flank you.
- **Flee:** BFS for the safest reachable tile out of your sight. It slowly heals while hidden.

## Where the graded code is
| File | Topic |
| --- | --- |
| scripts/search/bfs.gd | BFS (uninformed search) |
| scripts/search/astar.gd | A* with Manhattan heuristic |
| scripts/search/dstar_lite.gd | D* Lite (incremental replanning) |
| scripts/search/minimax.gd | Minimax + alpha-beta (adversarial search) |
| scripts/search/pq.gd | binary-heap priority queue |
| scripts/items.gd | ontology: item categories and rules |
| scripts/agent/castle_belief.gd | partial observability + default reasoning |
| scripts/agent/thief.gd | the agent: utility decisions, method selection, sense-plan-act |

## Tests
- `godot --headless -s tests/run_tests.gd`: BFS / A* / D* Lite correctness on 40 random changing maps.
- `godot --headless -s tests/test_thief.gd`: thief scenarios (unguarded, doors locked, guarded chest).
- `godot --headless -s tests/test_chase.gd`: thief vs a scripted chasing knight.

Map: levels/castle.txt (64x48, 12 rooms), generated by tools_make_castle.py, which also checks every room is reachable and the vault has exactly 3 ways in.
Art: Kenney Tiny Dungeon (CC0), assets/kenney/.
